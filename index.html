텔레파시 질문

진행 방법

이지선다

  • 사회자가 질문과 두 보기를 읽어준다
  • "하나, 둘, 셋!"에 맞춰 1번이면 손가락 1개, 2번이면 2개를 동시에 내민다
  • 다수와 같은 쪽을 낸 사람 +1점, 전원이 같으면 전원 +3점
  • 5:5로 갈리면 이번 라운드는 무효

주관식

  • 사회자가 질문을 읽어준다
  • 3초 동안 생각한 뒤, 사회자가 "하나, 둘, 셋!"
  • 모두 동시에 한 단어로 외친다
  • 가장 많은 사람과 같은 답이면 +1점, 전원 일치하면 전원 +3점
  • 변형: 2명씩 짝을 지어 둘이 똑같은 답을 외치면 성공

마피아 룰북

역할 구성

사회자 1명 + 플레이어 9명 = 총 10명

  • 사회자1명진행 담당 (플레이 X)
  • 마피아2명마피아팀
  • 경찰1명시민팀
  • 의사1명시민팀
  • 시민5명시민팀
* 다른 역할인 척 속이면서 플레이하셔도 됩니다.

승리 조건

시민팀 승리마피아 2명을 모두 처형하면 승리
마피아팀 승리생존한 마피아 수가 생존한 시민팀 수와 같아지면 승리 (예: 마피아 2 : 시민팀 2)

준비

  • 사회자가 역할 쪽지 9장(마피아2·경찰1·의사1·시민5)을 섞어서 1장씩 나눠줌
  • 내 역할은 끝까지 비밀! 확인 후 접어서 보관
게임 흐름
밤→아침(사망 발표)→토론→투표·처형
승패가 날 때까지 반복

역할별 능력

마피아 2명
  • 첫날 밤, 눈을 떠서 서로 정체 확인
  • 매일 밤 둘이 합의해 1명을 지목, 지목당한 사람은 사망
  • 같은 마피아는 지목 불가
  • 낮에는 시민인 척 연기!
경찰 1명
  • 매일 밤 1명을 지목해 마피아인지 확인
  • 사회자가 마피아면 고개 끄덕, 아니면 가로젓기
  • 정체를 공개할 타이밍은 본인이 판단
의사 1명
  • 매일 밤 1명을 지목해 보호
  • 마피아가 지목한 사람과 같으면 생존
  • 자기 자신 보호는 게임 중 1회만
시민 5명
  • 특수 능력 없음
  • 낮 토론과 투표로 마피아를 찾아내기
사회자
  • 모든 정체를 알고 공정하게 진행
  • 사회자 판정이 최종 결정

밤 진행 순서

사회자 멘트 대본

  1. "밤이 되었습니다. 모두 눈을 감아주세요."
  2. "마피아, 눈을 뜨세요. 죽일 사람을 지목하세요."
    지목 확인 후 "마피아, 눈을 감으세요."
  3. "경찰, 눈을 뜨세요. 조사할 사람을 지목하세요."
    끄덕/가로젓기로 알려준 뒤 "경찰, 눈을 감으세요."
  4. "의사, 눈을 뜨세요. 살릴 사람을 지목하세요."
    지목 확인 후 "의사, 눈을 감으세요."
  5. "아침이 밝았습니다. 모두 눈을 뜨세요."
사회자 팁
  • 순서는 항상 마피아 → 경찰 → 의사
  • 지목은 손가락으로만 (말 금지)
  • 이미 죽은 역할도 똑같이 호출하고 같은 시간만큼 기다리기 (정체 들킴 방지)
  • 밤에 눈 뜬 사람 외에는 눈 감고 고개 숙이기

낮 진행

  1. 사망 발표
    사회자가 사망자 이름만 발표. 의사가 살렸다면 "아무도 죽지 않았습니다"
  2. 자유 토론
    생존자 전원 발언. 거짓말·연기 OK! (제한 시간 3~5분)
  3. 투표
    사회자 "하나, 둘, 셋!"에 동시에 의심되는 사람 지목 → 최다 득표 1명 처형
동점이면?동점자만 최후 변론 30초 후 재투표, 또 동점이면 처형 없이 밤으로

꼭 지켜요

  • 사망자는 말·표정·눈짓 금지 (조용히 관전)
  • 처형·사망 시 역할은 공개하지 않음
  • 역할 쪽지 보여주기, 메모·핸드폰 사용 금지
  • 사회자 판정이 최종
